# EasyCalc

EasyCalc is a free online calculator website. The Dutch calculator pages currently cover:

- Cijfer berekenen, gewogen gemiddelde and benodigd cijfer
- Percentage, korting and BTW
- Bruto uurloon and an indicative bruto-netto estimate for tax year 2026
- Tijdsduur
- BMI, with a note that BMI for under-18s needs age and growth context

## Development notes

The calculator landing pages share `calculator-tools.css` and `calculator-tools.js`. Each public calculator page should have a unique Dutch title, meta description, canonical URL, accessible labels, validation, a reset action, a copy-result action, an example and a link back to the homepage.
